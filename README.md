# ked-motion-tool

캐릭터 모션 전용 저작 도구. 무대 런타임(`ked-stage-runtime`)이 읽는 `motions.json`(`motions/2`)을
마야급 커브 편집으로 만든다. 계획 전체는 [`docs/PLAN.md`](docs/PLAN.md).

- **v1**: 초상화 한 장을 리그 축(`Track_Move_*`·`SwayPivot`…)으로 움직이는 단순 캐릭터 모션. 그래프
  편집기(키·탄젠트)·뷰포트·도프 시트.
- **v2 이후**: 카메라·depth·intent 채널, Spine 식 다중 스프라이트 리그, 컷인·배경 연출.
- 툴은 Yarn·커맨드를 **모른다**. 산출물은 `motions.json` 하나다.

## 처음 써 보기 (10분)

리그는 툴에서 **만들지 않는다**. 유니티가 이미 내보낸 덤프 `ExportedTuning/rig-schemas.json`(ked-stage-runtime·ked-presentation-runtime 둘 다 같은 파일)을 읽는다 — 노드 이름·계층·앵커·피벗이 전부 거기서 온다.

1. **실행** — 저장소 루트에서:
   ```
   dotnet run --project src/Mt.App/Mt.App.csproj
   ```
2. **리그 덤프…** → `ked-stage-runtime/ExportedTuning/rig-schemas.json`. 옆의 `base-resolution.json`도 같이 실린다. 상태 줄에 `리그 덤프: character, background, screenEffect · 무대 1920×1080`.
3. **초상 PNG…** → `ked-presentation-runtime/Assets/Samples/Portraits/harin/b/01.png`. 뷰포트에 초상이 선다(없으면 자리표시 사각형).
4. **motions.json 가져오기…** → `ked-presentation-runtime/Assets/Samples/Dialogue/motions.json`. 왼쪽 "모션"에 `nod`·`bow`가 생긴다.
5. `nod`를 고르고 **Alt+`** — 끄덕인다. `bow`는 끝에서 8도 기운 채 남는다(commit).
6. 그래프 탭에서 키를 끌어 본다 — 놓는 순간 뷰포트가 따라오고, Ctrl+Z로 돌아온다. 도프 시트 탭에서 블록을 끌면 시간이 옮겨진다.
7. **다른 이름으로…** → `*.motion-authoring.json`으로 저장(저작 원본). **motions.json 내보내기…** → 런타임이 읽는 산출물. 아래 문제 칸이 비어 있을 때만 나간다.

**프리셋에서 시작하기**: 왼쪽 모션 칸의 콤보에서 **끄덕·젓기·깡충·움찔·떨림·숙임·바운스·호흡·돌아서기** 중 하나를 고르고 **프리셋에서 추가** — 선택 오브젝트의 리그에 컨트롤러 표의 노드로 모션이 생긴다(이름은 `nod`, 겹치면 `nod_2`; 되돌리기 하나). 전부 연기(relative) 컨트롤러라 어느 자리·깊이에서도 같고, 규칙·경고 없이 바로 내보내진다. 돌아서기만 `commit`(방향 × −1이 남는다). 값은 그래프에서 다듬는다.

**처음부터 만들기**: 왼쪽 **모션 추가**(이름 `motion`·선택 오브젝트의 리그·길이 1초·종료 처리 `복원(restore)`으로 생긴다 — 오른쪽 인스펙터에서 이름 `wave`, 길이 `0.5`로 바꾼다). 하이어아키에서 `s1 › … › CharacterPortrait_Track_Move_X` 노드를 클릭하면 오른쪽 **채널 박스**에 그 노드의 Translate/Rotate/Scale이 보인다. **Auto Key**를 켜고 현재 시각을 `0.25`로 두고 Translate X에 `30` Enter — 채널·성분·키가 한 번에 생긴다. 현재 시각 `0.5`에서 `0` Enter. 전체 선택 후 **flat(2)**. 문제 칸이 비면 내보낸다.

## 그래프 에디터 (마야 그래프 에디터 그대로)

아래 "그래프" 탭. 왼쪽 **아웃라이너** · 위 **툴바** · 회색 플롯(재생 범위 안은 밝게, 위 눈금자는 **프레임**, 값은 왼쪽, 현재 시각은 노란 선과 마커). 시간 표시는 설정에서 초로 바꿀 수 있다(칸에는 `12`·`12f`·`0.5s`처럼 단위를 붙여 쓸 수 있다).

| 조작 | 뜻 |
|---|---|
| 아웃라이너 | 컨트롤러 표가 있는 리그면 **모션의 컨트롤러 전부**(10개)가 표 순서 그대로(순서는 바뀌지 않는다): 고른 컨트롤러는 굵게, 키 없는 것은 흐리게. **컨트롤러를 고르면**(하이어아키·아웃라이너) 그래프는 그 컨트롤러의 커브만 보이고, 키가 없으면 빈 그래프다. 컨트롤러 밑은 표가 쓰는 성분만(깊이는 배율 X·Y + 깊이 Y). 컨트롤러 이름 클릭 = 고르기 + 그 커브만(Shift/Ctrl: 더하기) · 성분 클릭 = 그 커브만 · **흐린 성분을 클릭해도 성분은 생기지 않는다**(마야식 — 성분은 키를 놓을 때만 생긴다) · 성분 행의 × = 그 성분만 삭제(마지막 성분이면 채널이 없어진다) · 컨트롤러 행의 🔓/🔒 · 🔊/🔇 · ×(키 전부). 검색은 컨트롤러 이름·id·노드. "리그 노드 보기"면 모션의 채널을 노드로 |
| 클릭 · Shift+클릭 · 빈 자리 드래그 · Ctrl+드래그 | 키 선택 · 추가 선택 · 박스 선택 · 라소. 박스에 키가 들면 **키만**(커브는 하얘지지 않는다), 키 없이 커브만 지나면 커브 선택. 키를 고른 채 **탄젠트 핸들 끝을 박스로** 고르면 핸들 선택(키 선택은 그대로) |
| **커브 선 클릭** · Shift+클릭 · **박스 드래그가 커브를 지나면** | 커브 선택(흰색 굵게) · 더하기/빼기 · 정확히 안 눌러도 상자가 지나는 커브가 선택된다. 빈 자리 클릭은 푼다 |
| 커브를 고른 채 **MMB 클릭** | 그 커브 위, 그 시각(스냅)에 키(값은 곡선 위) — 마야 Insert Key |
| 선택 키 둘레에서 **RMB 드래그** · **Shift+RMB 드래그** · 빈 자리 **RMB 드래그** | 처음 움직인 쪽으로만(가로 = 시각, 세로 = 값) 한 번에 이동 · Shift면 정수 프레임(1fr, 2fr…)·정수 값에 스냅 · 화면 이동(팬) |
| **MMB 드래그** (어느 툴이든) · 이동 툴(**W**)의 LMB 드래그 · Shift = 축 잠금 | 선택 키 시간·값 이동(마야). 핸들을 고른 상태면 **그 핸들들을 돌린다**(편집 하나). 선택 툴(**Q**)의 LMB는 고르기만. 시간은 스냅, 값은 **값 스냅**을 켜면 정수 |
| 스케일 툴(**R**) LMB 드래그 · Shift = 한 축만 | 선택 중심(피벗) 기준 값·시간 스케일 — 오른쪽 = 시간, 위 = 값 |
| **리전 툴**(툴바 "리전" 토글) | 상자로 고르면 상자가 남는다. 상자 안 드래그 = 이동, 왼/오른 모서리 = 반대쪽 끝 기준 시간 스케일, 위/아래 모서리 = 값 스케일. 다시 누르면 선택 툴(Q)로 |
| 위 눈금자 클릭·드래그 | 스크럽 |
| **I** · **A** · **F** · 툴바 재생 범위 | 현재 시각에 키(값은 곡선 위) · 전체 맞춤 · 선택 맞춤 · 재생 범위 맞춤(마야 Frame All / Frame Selected / Frame Playback Range). 툴바에는 재생 범위만 — 선택(Q)·이동(W)·스케일(R)·끼우기·전체·선택·현재 시각 가운데 버튼은 뺐다(소유자) |
| 툴바 auto · spline · linear · flat · plateau · 끊기 · 붙이기 · **Ctrl+1 … Ctrl+6**(4 = free, 버튼 없음) | 선택 키 탄젠트. **탄젠트 핸들**(선택 키 양쪽의 흰 선, 네모 끝 — 마야의 tangent handle) 끝을 LMB로 끌거나, 박스로 골라 MMB로 끌면 기울기(끊긴 키는 한쪽만). 새 키의 탄젠트는 "보기 › 새 키 탄젠트" (가중·계단 탄젠트는 규약이 거부한다) |
| 툴바 버퍼 찍기/바꾸기(한 버튼) · 버퍼 지우기 · **Ctrl+B** · **Ctrl+Shift+B** | 버퍼가 없으면 보이는 커브를 흐린 점선으로 찍어 두고, 있으면 찍어 둔 것과 지금을 바꾼다(마야 Buffer Curve). 새로 찍으려면 지운 뒤 |
| 툴바 무한(앞 · 뒤): 상수 / 사이클 / 사이클+오프셋 / 왕복 / 직선 | 마야 Pre/Post Infinity — 첫/마지막 키 밖을 흐린 점선으로 이어 보인다(보기만 — 산출물의 끝은 restore/commit) |
| 툴바 값 칸 `+=3` `-=1` `*=2` `/=2` · 기울기 in/out 칸 | 선택 키 전부에 상대 적용(마야 채널 박스). 숫자는 절대값. 시각 칸은 없다 — 시각은 끌거나 도프 시트로 |
| **Ctrl+C / X / V** (창 어디서나, 그래프·도프 시트 공용) | 복사 · 잘라내기 · 현재 시각에 붙여넣기(가장 이른 키를 현재 시각에, 같은 시각은 덮어씀, 없는 채널은 만든다). **붙이는 커브**: 고른 커브 선이 있으면 그것, 없고 복사한 커브가 안 보이면(아웃라이너에서 다른 커브만 띄운 상태) 보이는 커브, 그 밖에는 복사한 커브 — 그래서 scale X의 키를 복사해 scale Y만 띄우고 붙이면 Y에 들어간다(복사한 커브가 하나면 모든 대상에, 여럿이면 순서대로 짝) |
| 더블클릭 · **Delete** · **Ctrl+Z / Y** | 커브 위 그 시각에 키 · 키 삭제 · 되돌리기/다시하기 |
| 휠 (Ctrl = 시간만 · Shift = 값만) · **Alt+MMB** · **Alt+RMB 드래그** | 줌 · 팬 · 줌 드래그(오른쪽 = 시간, 위 = 값) |
| 툴바 보기: 절대 / 정규화 / 쌓기 | 마야 Normalize·Stacked — 커브마다 제 범위를 0~1로 눌러 모양만 견준다. 끌면 값은 실제 단위로 바뀐다 |

## 타임 슬라이더 · 레인지 슬라이더 · 트랜스포트 (마야 그대로)

뷰포트 아래 두 줄. 위 줄은 **타임 슬라이더**(재생 범위를 프레임 눈금으로, 빨간 키 틱, 현재 프레임은 검은 상자) + `[현재 프레임] ⏮ |◀ ◁ ◀ ▶ ▷ ▶| ⏭`. 아래 줄은 `[0][범위 시작] ═레인지 바═ [범위 끝][길이]` + 재생 모드 · 속도 · 24 fps · **Auto Key**.

| 조작 | 뜻 |
|---|---|
| LMB 클릭·드래그 | 스크럽(프레임 스냅). 빨간 범위 선택은 지워진다 |
| **Shift+LMB 드래그** | 범위 선택(빨강, 프레임 단위). 한 프레임만 고르면 그 프레임의 키가 선택된다 |
| 범위 안 **MMB 드래그** · 범위 양끝 LMB 드래그 | 범위의 키 이동 · 반대쪽 끝 기준 시간 스케일(놓을 때 편집 하나, 끄는 동안 노란 유령 틱) |
| 범위 밖 **MMB 드래그** | **포즈 들고 스크럽** — 보이는 포즈는 그대로 두고 시각만 간다(현재 프레임 상자에 점선 테두리). **S**로 그 포즈를 그 프레임에 키(모든 채널, 되돌리기 한 번) · Esc/보통 스크럽은 버린다 |
| RMB 메뉴 | 키 잘라내기/복사/붙여넣기/삭제(범위, 없으면 현재 프레임) · 키를 프레임에 스냅 · 재생 범위를 선택으로/전체로 · 범위 선택 지우기 · 재생 모드 · 재생 속도 · 키 틱 표시(전체/선택/없음) |
| 레인지 바 끌기 · 양끝 · 더블클릭 | 재생 범위를 통째로 옮기기 · 크기 · 전체 ↔ 직전 범위 |
| 길이 칸 | 모션 길이(애니메이션 끝). 바꾸면 길이가 바뀐다 |
| ◀ · ▶ | 거꾸로 재생 · 재생(한 번/루프/왕복 모두 거꾸로 된다) |
| 재생 표시: 연속 / 프레임 맞춤 (24 FPS) | 둘 다 실제 시간으로 재생한다. **연속**은 실제 경과 시간에 해당하는 자세를, **프레임 맞춤**은 표시 시각을 가장 가까운 24 FPS 프레임에 맞춘 자세만 보여준다(느린 환경에서는 중간 프레임을 건너뛸 수 있다). 기본은 연속. 설정에 남는다 |

## 전역 단축키 (마야 타임 슬라이더)

창 어디에 포커스가 있든 듣는다(글 입력 칸만 예외). 버튼은 따로 없다 — 전체 표는 툴바 **단축키 (F1)** 창에.

| 키 | 뜻 (마야) |
|---|---|
| **1** · **2** | 이전 키 · 다음 키 |
| **Alt+1** · **Alt+2** | 이전 프레임 · 다음 프레임 (24fps, ←/→와 같다) |
| **`** | 첫 프레임(재생 범위 처음)으로 |
| **Alt+Q** · **Alt+`** | 재생 토글 (PlaybackToggle) · 처음부터 재생(범위 시작으로 되감고 재생) — Space는 쓰지 않는다 |
| **Shift+W** | 현재 시각의 키 전부(모든 커브) 복사 (timeSliderCopyKey) |
| **Shift+E** | 현재 시각에 붙여넣기 — 같은 시각은 덮어쓰고 없는 채널은 만든다 (timeSliderPasteKey) |
| **Shift+F** | 현재 시각의 키 전부 지우기 (timeSliderClearKey) |
| **Q** · **W** · **E** · **R** | 매니퓰레이터 선택 · 이동 · 회전 · 배율 (그래프 안에서는 Q/W/R이 그래프 도구) |
| **Shift+1** · **Shift+2** | 인비트윈 빼기 · 넣기 — 현재 시각 **뒤**의 키를 한 프레임 당기거나 민다. 그 시각의 키는 안 움직이고, 당겨서 닿으면 움직인 키가 이긴다 (timeSliderEditKeys removeInbetween / addInbetween) |

| 조작 | 뜻 |

## 씬 · 오브젝트 · 월드 축 (`docs/PLAN-scene.md` S1–S8)

- **덤프 없이 시작한다.** 런타임 `ExportedTuning/`(리그 덤프 · 기준 해상도 · 깊이 커브 · focus 표)의 사본이 내장되어 있어(`Mt.Authoring/Defaults`, 원본 커밋은 `BuiltinTuning.Source`) 새 문서를 열면 바로 캐릭터 리그가 선다. 상태 줄에 "내장 리그(…)"로 보인다. "리그 덤프…"로 파일을 실으면 그것이 우선하고, 문서가 기억한 덤프 파일이 없으면 내장본으로 열며 알린다.
- **무대 뼈대**: 유니티 `PresentataionUIRoot.prefab`에서 뽑은 85노드(`StageViewportLayer › StageShot_Root › StagePan_Root › StageZoom_Root › Stage00~02_Root › Mask › DepthSystem › Depth_{Far…Close} › FramingTransform › FramingScale › Content`, 전부 항등)를 코어 `AddRigTo`로 먼저 세우고(`stage/…` 키), 오브젝트는 그 무대·층의 `Stage{NN}Depth_{Layer}_Content` 밑에 선다 — 런타임 `GetDepthContent(stage, layer)`와 같은 자리. 뼈대는 데이터(`Defaults/stage-skeleton.json`, `tools/prefab-to-stage-rig.py`로 다시 뽑는다)이고 오브젝트가 아니다.
- 왼쪽 **씬 — 오브젝트** 하이어아키(유니티 하이어아키와 같은 모양): `Scene › Stage00 › 층(Content) › 오브젝트 › 자리/깊이/연기 › 컨트롤러`. 오브젝트 밑은 기본으로 리거의 컨트롤러 표(`presets/controllers.json`, 없으면 내장본)다 — 묶음 폴더(`자리 · 절대값`, `깊이 · 절대값`, `연기 · 상대값` — 재생 기준, 툴팁에 대본 낱말) 안에 `몸 · position XY`, `숙임 · rotate Z` 같은 손잡이. **컨트롤러를 클릭**하면 그 주 노드가 채널 박스·매니퓰레이터의 노드가 되고, 매니퓰레이터가 선택(Q)이 아니면 종류(이동·회전·배율)에 맞춰 바뀐다. 도프 시트 노드 행과 아웃라이너 채널 이름도 `연기 · 몸`(별칭 노드는 `연기 · 몸 Y`)으로 보인다. 설정 창의 **리그 노드 보기**를 켜면(리거용) 아래처럼 덤프 노드 26단이 그대로다. 무대 뼈대(`StageViewportLayer › … › FramingScale`)는 기본으로 숨겨 `Scene › Stage00 › mid › 오브젝트`만 보이고, 설정 창의 **무대 뼈대 보기**로 전부 연다. 뼈대 전체(`StageViewportLayer › StageShot_Root › StagePan_Root › StageZoom_Root › Stage00_Root › Mask › DepthSystem › Depth_Mid_Root › FramingTransform › FramingScale › Content`)가 그대로 보이되, 오브젝트가 선 가지만 기본 펼침이고 나머지는 접혀 있다(유니티처럼 필요할 때 펼친다). 리그 노드는 덤프 `rig-schemas.json`의 `parent` **그대로 중첩**된다. 오브젝트 항목이 곧 리그 루트(`__root`)다. 연기 축은 파랑, 배치 축은 회색, 키잉 금지 노드는 기울임이다. 오브젝트는 기본 접힘(우클릭 "노드 전부 펼치기/접기"). **노드를 클릭**하면 그 노드가 채널 박스·매니퓰레이터의 노드가 된다(키 따라가기는 꺼진다). "채널 추가"는 없다 — 채널 박스에 값을 넣거나 매니퓰레이터로 끌면 첫 키에서 채널·성분이 생긴다. 기본 씬은 `s1 · character`(Stage00 Mid) 하나다.
- **만들 수 있는 것은 캐릭터 리그뿐이다.** 헤더의 **`+ 캐릭터 리그`** 버튼이 바로 만든다 — 층(Content)·Stage 항목을 고른 채면 거기에, 오브젝트/노드/컨트롤러를 고른 채면 그 오브젝트와 같은 무대·층에, 아무것도 안 골랐으면 선택 오브젝트의 무대·층(없으면 Stage00 Mid)에. 우클릭 → "캐릭터 리그 만들기"(Ctrl+Shift+N)도 같다. id는 자동(`s1`·`s2`… — Yarn 슬롯 키 꼴)이고 F2로 바꾼다. 그 밖의 메뉴: 이름 바꾸기(F2) · 복제(Ctrl+D) · 삭제(Del) · 숨기기/보이기 · 레이어 › · 노드 전부 펼치기/접기.
- **오브젝트끼리 부모·자식은 없다**(소유자 결정, 2026-10-28). 오브젝트는 모두 그 무대·층의 Content에 선다 — 런타임 슬롯과 같다(런타임에도 슬롯을 슬롯에 붙이는 커맨드가 없다). 하이어아키 드래그, 부모 콤보, "부모에서 떼기", 월드 자세 보존 환산은 그래서 없다. 층·무대는 우클릭 "레이어 ›"와 씬 탭에서 바꾼다.
- 오른쪽 **씬 탭**(고른 오브젝트의 배치, 모션 키가 아니다): **자리(place) × focus** · Layer · Stage · 보이기, 접힘 "시작 배치"(오프셋 X/Y(move) · Rot Z · Scale X/Y) · "카메라(샷)". id 칸은 없다 — 이름 바꾸기는 하이어아키 F2. 부모·노드·배역은 없다(아래). 접힌 묶음은 값이 기본이 아니면 스스로 펼친다. 런타임과 같은 두 겹이다: **자리**는 코어 place 폴드(`PlaceFocusStageReduction`)가 focus 프리셋(bust 기본) 점이 화면 지점(center/left/right/top/bottom/tl/tr/bl/br)에 오도록 `CharSlot_Track_Focus`를 푼 값이고, **오프셋**은 `CharSlot_Track`(move)·`CharSlot_SwayPivot`(rotate)·`CharSlot_Scale`(scale)에 그대로 들어간다(그 노드가 없는 리그는 루트에). 순서는 런타임 대본과 같이 깊이(size) → place → 오프셋이라(자리를 잡은 뒤 오프셋만큼 더 간다 — place는 오프셋을 되감지 않는다) 내장 깊이·focus 표로 세우면 실제 게임 프리팹의 `DepthY −580.56 · DepthScale 1.708`(Stage00 Mid)이 그대로 나온다. 모션 키가 아니다.
- **월드 축·격자**: 루트 공간(가운데 원점·y 위·px). 빨강 x·초록 y 축, 가는 선 1u(기준 폭/48 = 40px), 굵은 선 5u, 무대 프레임. 항상 보인다.
- **모션의 주인은 rigKind**다. 고른 오브젝트의 리그가 모션의 리그와 같거나 채널의 노드를 전부 가지면(공통 스키마) 그 오브젝트에 입혀 보인다. 아니면 "이 리그에 안 맞는다"로 표시된다.
- **깊이 컨트롤러**(채널 박스의 슬라이더 0..40, close = 20, 그 너머는 `depth.json` 커브의 할선 연장 — 런타임과 같은 규칙): 놓으면 level의 배율을 `CharSlot_DepthScale` X·Y에, `−bust높이(820) × (배율 − 1)`을 `CharSlot_DepthY` Y에 굽는다(되돌리기 하나) — 런타임 `size`의 focus 보존이 정지 자세에서 남기는 값과 같아 얼굴은 제자리, 발은 멀수록 위로 간다(mid 14 = 1.708 · −580.56). 리거는 `controllers.json`의 `bakeY`를 빼서 끌 수 있다.
- **깊이**: 덤프 옆 `presets/depth.json`(ExportedTuning)이 있으면 레이어(far·back·mid·front·close)가 깊이(DepthY·DepthScale)가 된다. 런타임 size 폴드와 같은 코어 함수(`SetDepthStageReduction`, focus 보존 bust)를 지나므로 보이는 깊이 = 정지 프레임의 깊이다. 없으면 레이어는 그리는 순서만 정한다. **그리는 순서**는 유니티 하이어아키 그대로 무대 Stage00 → Stage01 → Stage02(뒤 무대가 앞에), 무대 안에서는 far → close, 같은 층은 만든 순이다.
- 채널 종류는 화면에서 `position · scale · rotate`로 부른다(파일 규약은 `euler` 그대로). **채널에 mode는 없다**(`motions/2`): relative/absolute는 대본의 `<<motion slot 이름 relative|absolute>>`(생략 = relative)가 정한다. 모션 탭의 **재생 기준**(상대값 relative / 절대값 absolute)은 툴이 키 값을 읽는 기준일 뿐이고 파일에 안 나간다 — 상대값이면 시작값 + 키(배율은 ×), 절대값이면 키 그대로. 매니퓰레이터·채널 박스가 포즈를 키 값으로 바꿀 때도 이 렌즈를 쓴다. 옛 `motions/1`·`motion-authoring/1`은 읽히고(채널 `mode` 무시, `defaultMode` → 재생 기준) 키 값은 그대로다.
- 씬은 하나만 쓴다(저작본 `scenes[]`와 편집기 명령은 여럿을 담을 수 있지만 UI는 활성 씬 하나만 보인다 — 모션 추출용이라 전환 UI는 뺐다).
- **배역은 없다.** 오브젝트는 리그만 가진다(저작본에 `character`가 없다). 덤프 옆 `presets/focus.json`(또는 `focus-tuning.json`)이 있으면 깊이·place 폴드의 focus 보존은 base 오프셋 + bust만 쓴다(배역 키는 빈 문자열) — 런타임에서 cast 없이 세운 것과 같다. 표가 없으면 base 오프셋 없이(0).
- **카메라(샷)**: 씬 탭의 접힘 zoom · pan X/Y. 런타임과 같은 자리에 들어간다 — `StageZoom_Root.localScale = 1 + 0.05·zoom`, `StagePan_Root.anchoredPosition = pan`(`PresentationCameraRootApplier`). 깊이 층마다 패럴랙스(`PresentationResponseProfile`: Far는 pan×−0.04·scale^−0.15 … Close는 pan×0.2·scale^0.16, Mid는 0)가 `FramingTransform`·`FramingScale`에 붙는다(`StageShotResponse`). 격자·축은 `StageShot_Root` 공간이라 움직이지 않는다. 카메라 키는 규약에 없고 씬에만 남는다.
- **모션 목록**은 rigKind 순으로 묶이고, 고른 오브젝트가 입을 수 없는 모션은 흐리게("안 맞음"). 툴바의 **내보내기 범위**: 전체 / 이 rigKind만 / 이 오브젝트가 입는 모션만 — 고른 모션의 문제만 내보내기를 막는다.
- 씬은 저작본 `scenes[]`에 남고(미리보기 전용) `motions.json`에는 들어가지 않는다. 예전 문서의 `preview.portrait`는 열 때 첫 오브젝트의 초상이 된다.

## 뷰포트

- **보기(네비게이션)**: 휠 = 커서를 축으로 확대·축소(×1.15/칸, 0.2…10배) · **MMB 드래그** = 보기 이동 · **F**(뷰포트에 포커스) = 처음 자리(무대가 뷰포트에 맞게). 화면뿐이고 씬·카메라·키는 안 바뀐다.
- **창 배치**: 왼쪽(씬·모션) · 가운데 · 오른쪽(인스펙터·채널 박스) 사이의 세로 스플리터, 뷰포트와 그래프/도프 시트 사이의 가로 스플리터를 끌어 크기를 바꾼다. 타임 슬라이더·레인지 줄은 뷰포트에 붙어 늘 제 높이이고, 스플리터는 뷰포트와 그래프의 몫만 바꾼다. 폭과 비율은 설정 파일에 남아 다음에 열 때 그대로다.

- 오른쪽 패널은 **탭 셋** — **채널 박스**(기본) · **씬** · **모션**(이름·길이·종료 처리·재생 기준). 마지막 탭은 설정에 남는다. 설정과 단축키 표는 패널이 아니라 툴바의 **설정…** · **단축키 (F1)** 창이다. 단축키의 그림자 버튼(Q/W/E/R·S·Esc·키 복사/붙여넣기·인비트윈)은 없다 — 하단 줄의 **Auto Key** 토글 하나만 남는다.
- **채널 박스**(마야): 묶음 제목(자리 · 깊이 · 연기) 클릭 = 접기/펼치기(설정에 남는다). 표가 없는 리그는 하이어아키에서 고른 리그 노드의 **Translate X/Y · Rotate X/Y/Z · Scale X/Y** — 리그 노드는 유니티 계층 하나라 이 값 전부를 가진다. 칸의 값은 지금 시각의 포즈(키 없는 포즈 포함)다. 값을 넣으면(`+=3`·`-=1`·`*=2`·`/=2`는 지금 값에 상대) 매니퓰레이터를 놓은 것과 같다: **Auto Key**거나 그 시각에 키가 있으면 키, 아니면 키 없는 포즈(S로 키·Esc로 버림). 칸 색: 빨강 = 이 시각에 키, 연한 빨강 = 어딘가에 키, 주황 = 키 없는 포즈. 이름 클릭 = 그 커브를 그래프에(Shift/Ctrl: 더하기), **●** = 그 성분을 지금 값으로 지금 키(마야 Key Selected). 채널·성분은 첫 키에서 생긴다.
- **S(키 놓기)**: 키 없는 포즈(드래그·채널 박스·MMB 스크럽)가 있으면 그것을 키로. 없으면 **고른 컨트롤러의 성분 전부를 지금 값으로 현재 시각에** 키(마야 Set Key on selected) — 깊이는 배율 X·Y + 깊이 Y가 한 번에. 키 값은 재생 기준대로(상대값이면 시작값과의 차이). 키가 하나뿐인 성분은 규칙 위반(빨강)으로 남는다 — 두 번째 키를 놓거나 돕는 손 "길이 자리에 키 넣기".
- **매니퓰레이터**: **W** 이동 · **E** 회전 · **R** 배율 · **Q** 선택. 컨트롤러 표가 있는 리그에서는 W/E/R이 표의 기본 손잡이(`manipulator`: **몸·숙임·크기**)로 간다 — 고른 컨트롤러가 그 종류를 받으면(자리 X·Y를 고른 채 W) 그 노드 그대로, 다른 종류면 기본 손잡이의 노드로 옮긴다. 표에 없는 노드(리그 노드 보기)는 건드리지 않는다. 기즈모의 축 끝은 한 축만, 가운데는 자유. 놓는 순간 **Auto Key**면 키가 들어가고(바뀐 성분만), 아니면 "키 없는 포즈"로 남아 **S**로 키를 놓거나 **Esc**/시각 이동으로 버린다. 그 시각에 이미 키가 있으면 바로 덮어쓴다. 채널·성분이 없으면 만든다.
- 리그 덤프(`rig-schemas.json`)로 세운 트리 위에 초상 PNG 한 장. 사이징은 런타임 `HeightFitPreserveAspect`와 같다. 깊이 mid, 카메라 없음(v1).
- 포즈 = 코어 `MotionMath.Compose`. 길이를 지나면 restore는 시작 상태, commit은 마지막 키 — 재생도 그 규칙을 보여 준다.
- **Alt+Q** 재생/일시정지 · **Alt+`** 처음부터 재생 · **`** 첫 프레임 · **Home/End** 처음/끝 · **←/→** 한 프레임(24fps). 타임 슬라이더·그래프의 현재 시각과 하나다.
- 선택한 키의 노드에 피벗·x(빨강)·y(초록) 축.
- `base-resolution.json`은 리그 덤프 옆에서 자동으로 싣는다(없으면 1920×1080).

## 설정 · 저장

- **설정 창**(툴바 "설정…", 마야 Preferences): 리그 노드 보기 · 무대 뼈대 보기 · 시간 스냅 간격(1/24초 = 1프레임 기본 · 1/60 · 1/120) · 새 키 탄젠트 · 시간 표시 · 자동 저장. 바꾸는 즉시 적용, 닫을 때 저장. 시간 스냅 켬/끔과 값 스냅은 그래프 툴바에, Auto Key는 하단 줄에.
- 설정은 `%APPDATA%/ked-motion-tool/settings.json`(시간 스냅·시간 스냅 간격·새 키 탄젠트·Auto Key·시간 표시(프레임/초)·자동 저장 간격·창 배치·인스펙터 탭·접힌 묶음·무대 뼈대 보기·최근 파일 8개). 창을 닫을 때 저장. 테마는 마야처럼 어두운 색 고정.
- 자동 저장은 문서 옆 `<이름>.autosave.motion-authoring.json`(기본 5분, 바뀐 것이 있을 때만). 저장 상태는 건드리지 않는다.
- 아래 문제 칸의 각 줄에 **돕는 손** 버튼: 끝 키를 길이로 · 길이를 마지막 키에 · 길이 자리에 키 넣기 · 마지막 키를 중립값으로 · 첫 키를 0초로 · 끝을 commit으로 · 이름 고치기. 각각 되돌리기 한 번. 빨강 ⚠는 규칙(내보내기를 막는다), 노랑 △는 경고 — "restore인데 마지막 키가 중립값이 아니다(끝에서 시작값으로 튄다)"뿐이고 내보내기는 된다. 첫 키가 중립값이 아닌 것은 알리지 않는다 — "지금 값 +140에서 시작"은 뜻이다.
- 키가 있는 성분은 전부 내보낸다(상수 중립값도). 파일이 mode를 모르므로 "무변"인지 "그 값으로"인지 낼 때 정할 수 없다 — Unity 내보내기와 같은 규칙.
