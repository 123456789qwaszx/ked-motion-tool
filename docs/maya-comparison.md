# 마야 애니메이션 기능 대조 — ked-motion-tool M0–M4 현황

기준: ked-motion-tool `dev` @ M4 완료 시점. 비교 대상은 마야(2024)의 그래프 에디터·도프시트·타임 슬라이더·뷰포트 애니메이션 기능 중 **이 툴의 범위(초상화 한 장을 리그 축으로 움직이는 캐릭터 모션)에 뜻이 있는 것**이다. 애니메이션 레이어·컨스트레인트·블렌드셰이프·Time Editor(NLA)처럼 범위 밖인 것은 끝에 따로 적었다.

표기: **✓** 있다 · **△** 일부/다른 모양 · **✗** 없다

## 1. 지금 있는 것 (M0–M4)

| 영역 | 구현 |
|---|---|
| 데이터 | 저작 원본 `motion-authoring/2`(탄젠트 모드·끊김·미리보기 mode·메모·씬) ↔ 산출물 `motions/2`(채널 mode 없음 — 커맨드가 정한다). 내보낸 바이트가 Unity 내보내기와 같다. 코어 `MotionRules`로 편집 중 검증, 0건일 때만 내보내기 |

| 그래프 | 초×값, 축별 줌(휠, Ctrl/Shift), 팬(가운데/Alt+드래그), F/A. 클릭·Shift·박스 선택. 드래그(Shift 축 잠금), 시간 스냅 1/60. 더블클릭/I 키 끼우기(값은 곡선 위). Delete. 핸들 드래그(끊긴 키는 한쪽), 탄젠트 auto/flat/linear/free(1~4), 끊기/붙이기. 성분마다 색, 보이기 토글 |

## 8. 왜 아직 거슬리는가 — 추정

1. **뷰포트에서 포즈를 못 잡는다.** 마야 흐름은 "뷰포트에서 잡고(W/E/R) 키(S/AutoKey)"인데, 지금은 그래프나 인스펙터에서 숫자를 다뤄야 한다. 리그 노드가 전부 같은 자리에 겹쳐 있어 노드 고르기도 뷰포트에서 안 된다.
2. **키 위치가 시간 축에 안 보인다.** 타임 슬라이더 키 틱·다음/이전 키 점프가 없다.
3. **탄젠트 종류가 모자란다.** spline(마야 기본의 부드러움)·plateau(오버슈트 억제)·step이 없고, 새 키의 기본 탄젠트도 설정할 수 없다.
4. **조작 관습이 마야와 다르다.** 왼쪽 드래그가 곧 이동(선택과 이동이 한 몸), Alt+MMB/RMB 내비게이션 없음, 값 스케일 툴 없음.
5. **정규화 보기·값 라벨·복사/붙여넣기**가 없어 여러 채널을 같이 다듬기 불편하다.
6. 외형(격자·라벨·색·여백)은 아직 손질 전이다.
