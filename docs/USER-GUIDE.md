# ked-motion-tool 사용법

애니메이터·연출자용 안내. 설치부터 `motions.json` 내보내기까지, 그리고 화면별 조작 전부.
키 하나하나의 전체 표는 툴 안의 **단축키 (F1)** 창에도 있다.

## 1. 설치와 실행

| 방법 | 절차 |
|---|---|
| 소스에서 실행 | .NET 10 SDK 설치 → 저장소 루트에서 `dotnet run --project src/Mt.App/Mt.App.csproj` |
| 빌드만 | `dotnet build KedMotionTool.sln --configuration Release` |

처음 열면 **내장 리그**(유니티 덤프의 사본)로 캐릭터 `s1`이 선 빈 문서가 뜬다. 덤프 파일이나 초상 PNG가 없어도 바로 모션을 만들 수 있다. 상태 줄에 `내장 리그(…)`가 보이면 정상이다.

설정 파일은 `%APPDATA%\ked-motion-tool\settings.json`에, 자동 저장은 문서 옆 `<이름>.autosave.motion-authoring.json`에 남는다.

## 2. 화면 구성

```
┌ 툴바: 새로 · 열기… · 최근… · 저장 · 다른 이름으로… · 리그 덤프… · 초상 PNG… · motions.json 가져오기… · 내보내기… · 되돌리기 · 다시하기 · 설정… · 단축키 (F1)
├───────────────┬──────────────────────────────────┬──────────────────┐
│ 씬 — 오브젝트  │ 뷰포트 (무대·격자·초상·매니퓰레이터)  │ 인스펙터 탭 셋     │
│   하이어아키   │                                  │  채널 박스 (기본)  │
│ 모션 목록      │ 타임 슬라이더 · 트랜스포트          │  씬              │
│ 모션 추가      │ 레인지 슬라이더 · 재생 모드 · Auto Key│  모션            │
│ 프리셋에서 추가 ├──────────────────────────────────┤                  │
│ 내보내기 범위  │ 그래프 / 도프 시트 탭              │                  │
├───────────────┴──────────────────────────────────┴──────────────────┤
│ 문제 칸 (규칙 위반 ⚠ · 경고 △ · 돕는 손 버튼)                              │
└─────────────────────────────────────────────────────────────────────┘
```

패널 사이의 스플리터를 끌어 크기를 바꾼다. 폭과 비율은 다음에 열 때 그대로다.

## 3. 10분 안에 한 번 해 보기

1. **프리셋에서 시작**: 왼쪽 모션 칸의 콤보에서 `끄덕`을 고르고 **프리셋에서 추가**. 모션 `nod`가 생긴다.
2. **Alt+`** — 처음부터 재생. 캐릭터가 끄덕인다. **Alt+Q**는 재생/일시정지.
3. 아래 **그래프** 탭에서 키를 **MMB 드래그**로 옮겨 본다. 놓는 순간 뷰포트가 따라오고 **Ctrl+Z**로 돌아온다.
4. **도프 시트** 탭에서 블록을 끌면 시간만 옮겨진다.
5. **다른 이름으로…** → `*.motion-authoring.json`(저작 원본). **motions.json 내보내기…** → 런타임이 읽는 산출물. 문제 칸이 비어 있을 때만 나간다.

실제 리그·초상으로 보고 싶으면 **리그 덤프…**로 `ked-stage-runtime/ExportedTuning/rig-schemas.json`을, **초상 PNG…**로 `ked-presentation-runtime/Assets/Samples/Portraits/harin/b/01.png` 같은 파일을 싣는다. 덤프 옆의 `base-resolution.json`·`presets/depth.json`·`presets/focus-tuning.json`·`presets/controllers.json`은 자동으로 같이 실린다.

## 4. 모션을 처음부터 만들기

1. **모션 추가** — 이름 `motion`, 선택 오브젝트의 리그, 길이 1초, 종료 처리 `복원(Restore)`로 생긴다. 오른쪽 **모션** 탭에서 이름(소문자·숫자·`_`)·길이·종료 처리·재생 기준을 바꾼다.
2. 왼쪽 하이어아키에서 `s1 › 연기 · 상대값 › 몸` 같은 **컨트롤러**를 클릭한다. 오른쪽 **채널 박스**에 그 손잡이의 성분(좌우·상하 등)이 보인다.
3. 하단 줄의 **● Auto Key**를 켠다. 현재 시각을 `0.25`(또는 6프레임)로 두고 채널 박스의 값에 `30` Enter — 채널·성분·키가 한 번에 생긴다. `0.5`에서 `0` Enter.
4. 뷰포트에서 **W**(이동)·**E**(회전)·**R**(배율) 손잡이를 끌어도 같다. Auto Key가 꺼져 있으면 끈 결과는 **키 없는 포즈**(주황)로 남고, **S**로 키를 놓거나 **Esc**로 버린다.
5. 그래프에서 키를 전부 고르고 **flat**(Ctrl+2)으로 탄젠트를 평평하게. 문제 칸이 비면 내보낸다.

### 종료 처리와 재생 기준

| 항목 | 값 | 뜻 |
|---|---|---|
| 종료 처리 | 복원(Restore) | 길이를 지나면 시작 상태로 돌아간다. 마지막 키가 중립값이 아니면 경고(△)만 — 끝에서 튄다 |
| 종료 처리 | 유지(Commit) | 마지막 키가 남는다(예: `돌아서기`는 방향 ×−1이 남는다) |
| 재생 기준 | 상대값(Relative) | 툴이 키를 "시작값 + 키"(배율은 ×)로 읽는다. 파일에는 안 나간다 — 실제 뜻은 대본의 `<<motion slot 이름 relative\|absolute>>`가 정한다 |
| 재생 기준 | 절대값(Absolute) | 키 그대로. 자리·깊이 컨트롤러에 키를 놓으면 자동으로 이쪽이 된다 |

### 컨트롤러 세 묶음

| 묶음 | 손잡이 | 뜻 |
|---|---|---|
| 자리 · 절대값 | 자리(X·Y) · 슬롯 기울기 · 배율 | 무대 배치. 보통 모션이 아니라 씬 탭의 "시작 배치"로 둔다 |
| 깊이 · 절대값 | 깊이 슬라이더 0‥40 (close = 20) | 놓으면 배율 X·Y와 깊이 Y를 한 번에 굽는다(되돌리기 한 번) |
| 연기 · 상대값 | 몸(좌우·상하) · 기울기 · 발 기준 회전 · 떨림 · 크기 · 방향 | 모션의 본거지. 어느 자리·깊이에서도 같다 |

W/E/R은 표의 기본 손잡이(몸·발 기준 회전·크기)로 간다. 리거용 **리그 노드 보기**(설정)를 켜면 덤프 노드 26단이 그대로 보인다.

## 5. 뷰포트

| 조작 | 뜻 |
|---|---|
| 휠 · **MMB/RMB 드래그** · **F** | 커서 축으로 확대/축소 · 보기 이동 · 처음 자리. 화면만 바뀌고 씬·키는 그대로 |
| LMB 클릭 | 오브젝트 고르기 |
| **Q** / **W** / **E** / **R** | 선택 / 이동(화살표) / 회전(고리) / 배율(끝 상자). 축 끝은 한 축만, 가운데는 자유. 배율은 팔 방향으로 끈 거리 — 팔 하나만큼 밖이 ×2, 안이 0에 가깝고 가운데를 지나도 커지지 않는다 |
| **S** · **Esc** | 키 없는 포즈를 키로 / 버리기. 포즈가 없으면 S는 고른 컨트롤러의 지금 값 전부를 현재 시각에 키 |
| `` ` `` · **Home/End** · **←/→** · **Alt+1/2** | 첫 프레임 · 처음/끝 · 한 프레임(24fps) |
| **Alt+Q** · **Alt+`** | 재생/일시정지 · 처음부터 재생 |

무대 프레임 밖의 오브젝트도 그대로 그리고, 카메라에 안 잡히는 바깥은 회색으로 덮인다. 격자는 1u = 40px(기준 폭/48), 굵은 선 5u.

## 6. 그래프 에디터 (마야 그래프 에디터와 같다)

왼쪽 아웃라이너(컨트롤러·성분), 위 툴바, 플롯(위 눈금자는 프레임, 재생 범위 안은 밝게, 현재 시각은 노란 선).

| 조작 | 뜻 |
|---|---|
| 클릭 · Shift+클릭 · 빈 자리 드래그 · Ctrl+드래그 | 키 선택 · 더하기 · 박스(키가 들면 키만, 커브만 지나면 커브) · 라소 |
| 커브 선 클릭 · Shift+클릭 | 커브 선택(흰색) · 더하기/빼기 |
| 커브를 고른 채 **MMB 클릭** · 더블클릭 · **I** | 그 커브 위, 그 시각에 키 끼우기 |
| **MMB 드래그** | 선택 키 이동(시간·값). 핸들을 골랐으면 핸들 회전. Shift = 축 잠금 |
| 선택 키 둘레 **RMB 드래그** · 빈 자리 **RMB 드래그** | 처음 움직인 축으로만 이동(Shift = 정수 프레임·값 스냅) · 팬 |
| **W** 이동 툴 · **R** 스케일 툴 · **Q** 선택 툴 | LMB 드래그로 이동 · 선택 중심 기준 스케일(오른쪽 = 시간, 위 = 값) · 고르기만 |
| 툴바 **리전** 토글 | 상자가 남는다. 안 = 이동, 좌우 모서리 = 시간 스케일, 상하 = 값 스케일. 다시 누르면 선택 툴로 |
| 탄젠트 핸들(선택 키 양쪽 흰 선) | 끝을 LMB로 끌어 기울기. 박스로 고르면 MMB로 돌린다 |
| 툴바 auto · spline · linear · flat · plateau · 끊기 · 붙이기 · **Ctrl+1…6** | 선택 키 탄젠트(4 = free는 버튼 없음) |
| 툴바 버퍼 찍기/바꾸기 · 지우기 · **Ctrl+B** · **Ctrl+Shift+B** | 보이는 커브를 흐린 점선으로 찍어 두고 지금과 바꾼다 |
| 툴바 무한(앞·뒤) | 상수 / 사이클 / 사이클+오프셋 / 왕복 / 직선 — 보기만(산출물의 끝은 종료 처리) |
| 툴바 값 칸 `+=3` `-=1` `*=2` `/=2` | 선택 키 전부에 상대 적용. 숫자는 절대값 |
| **Ctrl+C / X / V** · **Delete** | 복사 · 잘라내기 · 현재 시각에 붙여넣기 · 삭제 |
| 휠(Ctrl = 시간만, Shift = 값만) · **Alt+MMB** · **Alt+RMB** | 줌 · 팬 · 줌 드래그 |
| **A** · **F** · 툴바 재생 범위 | 전체 맞춤 · 선택 맞춤 · 재생 범위 맞춤 |
| 툴바 시간 스냅 · 값 스냅 | 키 배치·이동·스크럽 시 시간을 간격(기본 1/24초)의 배수에 · 값을 정수에 |

아웃라이너에서 컨트롤러 이름 클릭 = 고르기 + 그 커브만(Shift/Ctrl: 더하기), 성분 클릭 = 그 커브만. 흐린 성분은 키가 없는 것이라 클릭해도 생기지 않는다(키를 놓을 때 생긴다). 성분 행의 × = 그 성분 삭제, 컨트롤러 행의 🔓/🔒 · 🔊/🔇 · × = 잠금 · 뮤트 · 키 전부 삭제.

## 7. 도프 시트

그래프와 **선택이 하나**다.

| 조작 | 뜻 |
|---|---|
| 블록 클릭 · Shift · 박스 | 선택. 요약 행의 블록 하나는 그 밑의 키 전부 |
| 블록 드래그 · Alt+드래그 · **Ctrl+D** | 시간 이동 · 복제 · 한 프레임 뒤에 복제 |

| 레인지 바 끌기 · 양끝 · 더블클릭 | 재생 범위 이동 · 크기 · 전체 ↔ 직전 범위 |

전역 키: **1 / 2** 이전·다음 키, **Shift+W / E / F** 현재 시각의 키 복사·붙여넣기·지우기, **Shift+1 / 2** 인비트윈 빼기·넣기, **Ctrl+Z / Y**(또는 Ctrl+Shift+Z) 되돌리기·다시하기. 창 어디에 포커스가 있든 듣고, 글 입력 칸 안에서만 글자 편집이 우선한다.

## 9. 씬 탭 — 오브젝트 배치 (모션 키가 아니다)

| 항목 | 뜻 |
|---|---|
| 자리(place) × focus | 코어 place 폴드로 focus 점(기본 bust)이 화면 지점(center/left/right/top/bottom/tl/tr/bl/br)에 오게 |
| Layer · Stage · 보이기 | far…close 층, Stage00~02 무대, 숨기기. 그리는 순서는 Stage00 → 02, 그 안에서 far → close |
| 시작 배치(접힘) | 오프셋 X/Y · Rot Z · Scale X/Y — 자리를 잡은 뒤 그만큼 더 간다 |
| 카메라(샷)(접힘) | zoom · pan X/Y. 런타임 `StageZoom_Root`·`StagePan_Root`와 같은 자리, 층마다 패럴랙스. 키는 없다 |

하이어아키의 **+ 캐릭터 리그**(Ctrl+Shift+N)로 오브젝트를 더한다. id는 `s1`·`s2`… 자동, **F2**로 바꾼다. 우클릭: 이름 바꾸기 · 복제(Ctrl+D) · 삭제(Del) · 숨기기/보이기 · 레이어 › · 노드 전부 펼치기/접기. 오브젝트끼리 부모·자식은 없다 — 모두 그 무대·층의 Content에 선다.

씬은 저작본에 남고 `motions.json`에는 들어가지 않는다. 모션의 주인은 **rigKind**다 — 고른 오브젝트의 리그가 다르면 모션 목록에서 "안 맞음"으로 흐려진다.

## 10. 내보내기와 문제 칸

- **내보내기 범위**(왼쪽 콤보): 전체 / 이 rigKind만 / 이 오브젝트가 입는 모션만. 고른 범위의 문제만 내보내기를 막는다.
- 빨강 **⚠**는 규칙 위반(내보내기 불가), 노랑 **△**는 경고(내보내기 가능). 각 줄의 **돕는 손** 버튼이 한 번에 고친다(되돌리기 한 번):
  끝 키를 길이로 옮기기 · 길이를 마지막 키에 맞추기 · 길이 자리에 키 넣기 · 마지막 키를 중립값으로 · 첫 키를 0초로 · 끝을 commit으로 · 이름 고치기.
- 규칙(코어 `MotionRules`): 이름은 소문자·숫자·`_`, 성분마다 키 둘 이상, 첫 키는 0초, 마지막 키는 길이, 시각 오름차순, 가중·계단 탄젠트 없음.
- 키가 있는 성분은 전부 나간다(상수 중립값도). 채널에 mode는 없다 — 뜻은 대본 커맨드가 정한다.

## 11. 설정 창

툴바 **설정…**: 리그 노드 보기 · 무대 뼈대 보기 · 시간 스냅 간격(1/24 기본 · 1/60 · 1/120) · 새 키 탄젠트 · 시간 표시(프레임/초) · 자동 저장 간격. 바꾸는 즉시 적용, 닫을 때 저장.
시간 스냅 켬/끔과 값 스냅은 그래프 툴바에, Auto Key는 하단 줄에 있다.

## 12. 자주 묻는 것

| 증상 | 이유 · 할 일 |
|---|---|
| 내보내기 버튼이 안 먹는다 | 문제 칸에 ⚠가 있다. 돕는 손을 누르거나 키를 고친다 |
| 키를 놓았는데 성분이 하나만 생겼다 | 바뀐 성분만 키가 된다(마야와 같다). 다른 성분은 값을 넣거나 S로 전부 키 |
| 채널 박스 값이 빨강/주황이다 | 빨강 = 이 시각에 키, 연한 빨강 = 어딘가에 키, 주황 = 키 없는 포즈(S로 키, Esc로 버림) |
| 회전 손잡이가 캐릭터 발 아래 멀리 있었다 | 2026-10-28부터 원점이 그림 밖이면 그림 가운데에 선다. 각은 그 중심 기준 |
| 상태 줄에 "리그 덤프가 없어 내장본으로" | 문서가 기억한 덤프 경로에 파일이 없다. 리그 덤프…로 다시 싣거나 내장본으로 계속 |
| Ctrl+Z가 글자만 지운다 | 글 입력 칸 안이다. Enter로 확정하면 포커스가 뷰포트로 가고 그 뒤는 문서 되돌리기 |
| 자동 저장본이 보인다 | `<이름>.autosave.motion-authoring.json`은 5분마다(바뀐 것이 있을 때만). 저장 상태는 건드리지 않는다 |
