# M5 계획 — 마야 수준의 편의 기능

근거: `maya-comparison.md`. 소유자 판정(2026-10-27): 표의 공백은 전부 **없으면 안 되는 필수 편의 기능**이다. 순서대로 하되, 단계마다 CI 녹색 + 헤드리스 테스트를 남기고 `dev`에 올린다.

규칙은 그대로다: 편집은 `MotionEditor` 명령, 드래그는 놓을 때 편집 하나, 산수는 `Mt.Authoring`의 순수 함수, 산출물은 규약 `motions/1`(**계단·가중 탄젠트는 규약이 거부하므로 넣지 않는다** — 규약 §91).

| 단계 | 내용 | 끝났다는 증거 |
|---|---|---|
| **M5a** 타임 슬라이더 — 완료 | 뷰포트 띠에 키 틱(선택 키는 노랑) · 다음/이전 키(`.` `,`) · 재생 범위(시작/끝 핸들·입력) · 재생 모드 한 번/루프/왕복 · 재생 속도 · 그래프 눈금자 스크럽 | 헤드리스: 틱 자리 = 키 시각, `.`로 키 점프, 범위 안에서 왕복 |
| **M5b** 뷰포트 조작 — 완료 | 노드 선택(뷰포트 노드 목록 + 축 표시) · 이동/회전/배율 매니퓰레이터(W/E/R) 드래그 · **Auto Key** · **Set Key(S)** · 채널 자동 생성(없는 채널은 묻고 만든다) | 뷰포트 드래그만으로 `nod`를 만든다 |
| **M5c** 탄젠트 — 완료 | spline(클램프 없는 Catmull-Rom) · plateau(극값 평탄 + 이웃 같으면 평탄) · 새 키 기본 탄젠트 설정 · 선택 키 탄젠트 종류 표시 | 산수 테스트 + 설정 저장 |
| **M5d** 그래프 조작 관습 — 완료 | 선택(LMB)과 이동(MMB·W) 분리 · Alt+MMB 팬 · Alt+RMB 줌 드래그 · 스케일 툴(R: 값·시간, 피벗=선택 중심) · 라소 · 선택 키 값 라벨 · 키 상대 입력(`+=`) | 헤드리스 조작 테스트 |
| **M5e** 보기·편집 보조 — 완료 | Normalize/Stacked 보기 · 복사/잘라내기/붙여넣기(현재 시각 기준 offset, merge) · 커브 잠금/뮤트 · 버퍼 커브(스냅샷 대조) · cycle 미리보기 | 왕복 테스트 |
| **M5f** 검증·설정·외형 — 구현 완료, 사용자 확인 대기 | 돕는 손(첫/마지막 키 중립값·길이를 마지막 키에·끝 키를 길이로) · relative 중립 성분 흐리게 · 설정(fps 눈금·스냅·기본 탄젠트·어니언 수) · 자동 저장·최근 파일 · 격자/라벨/색 손질 | 사용자 확인 |

## 상태 (2026-10-27)

M5a–M5f 전부 `dev`에 올라가 CI 녹색. 격자/라벨/색 손질(M5f 마지막 항목)은 실제 화면 피드백을 받아서 한다 — 소유자가 써 보고 거슬리는 것을 말해 주면 그 목록으로 진행한다. 이징 프리셋 굽기(`PLAN.md` M5)는 M6 뒤로.

뒤로 미룬 것: 모션 트레일(M5b 뒤 여유 있으면), 세로 스크롤 도프시트(채널이 많아지면), Playblast(GIF 내보내기), 브레이크다운 키.
