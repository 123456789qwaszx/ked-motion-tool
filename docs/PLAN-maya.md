# 마야 이식 계획 — 그래프 에디터 · 타임 슬라이더를 "그대로"

소유자 요청(2026-10-27): 마야 2019 그래프 에디터와 타임 슬라이더의 **외형·기능·조작을 그대로** 가져온다. 색과 배치만이 아니라 조작 방식 전부 — "안 쓰는 게 없다".

규칙은 변함없다: 편집은 `MotionEditor` 명령, 드래그는 놓을 때 편집 하나, 산수는 `Mt.Authoring` 순수 함수, 산출물은 `motions/1`(**가중·계단 탄젠트는 규약이 거부**).
시간은 내부적으로 초지만 **표시는 프레임(24fps)** 이 기본이다 — 마야의 화면과 같다(`TimeText`, 설정에서 초로 바꿀 수 있다).
