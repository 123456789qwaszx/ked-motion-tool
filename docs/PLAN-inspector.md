# 인스펙터(오른쪽 패널) 정리 — 조사와 제안 (2026-10-28)

소유자: "뭐가 뭔지 알아볼 수 없다. 마야처럼 애니메이션 편의가 우선. 불필요한 것이 너무 많고 정리가 안 됐다. 탭이 필요하다."
이 문서는 지금 오른쪽에 있는 것 전부를 하나씩 보고, 남길 것·옮길 것·없앨 것을 정한 뒤, 탭 구성을 제안한다. 구현은 §5 순서로.

## 2. 원칙 (마야)

- **채널 박스가 주 화면**이다. 마야의 오른쪽은 채널 박스가 기본이고, 어트리뷰트 에디터는 탭으로 갈아탄다. 키를 놓는 동안 오른쪽에 다른 것이 보일 이유가 없다.
- **설정은 환경설정**으로. 작업 화면에 늘 떠 있지 않는다.
- **키 편집은 그래프 에디터 안**에서. 마야의 Stats(시각·값)·탄젠트 버튼은 그래프 에디터 툴바에 있다. 인스펙터에 또 두지 않는다.
- **버튼은 단축키의 그림자가 아니다.** 단축키가 있는 명령은 버튼을 두지 않거나, 두더라도 그 명령이 일어나는 자리(뷰포트·그래프) 곁에 둔다.
- **같은 토글은 한 곳에만.** Auto Key가 두 곳에 있다.

## 3. 제안 — 오른쪽 패널 = 탭 넷

```
┌ 채널 박스 │ 씬 │ 모션 │ 설정 ┐
```

### 3.1 채널 박스 (기본 탭, 애니메이터)

```
s1 · character                       (고른 오브젝트 · 리그)
▾ 자리 · absolute
   자리 X        [    0 ] ●
   자리 Y        [    0 ] ●
   슬롯 기울기   [    0 ] ●
   자세 배율 X   [    1 ] ●
   자세 배율 Y   [    1 ] ●
▾ 깊이 · absolute
   깊이          [━━●━━] [ 14 ] ●
▾ 연기 · relative
   몸 X          [    0 ] ●
   몸 Y          [  -18 ] ●
   기울기        [    0 ] ●
   숙임          [    0 ] ●
   떨림 X        [   -3 ] ●
   떨림 Y        [    0 ] ●
   크기 X        [    1 ] ●
   크기 Y        [    1 ] ●
   방향          [    1 ] ●
키 없는 포즈: 몸 X·Y — S로 키 · Esc로 버림     (떠 있을 때만)
```

- 섹션은 **접힌다**(▾/▸). 접힘 상태는 설정에 남는다. 기본은 전부 펼침 — 연기가 아래에 있어 스크롤이 생기면 자리·깊이를 접는다.
- 줄은 지금보다 **낮게**(값 칸 높이 22 → 18, 줄 간격 0). 라벨 폭 고정, 값 칸은 남은 폭, ● 는 그대로(이 성분만 지금 키 — 마야의 "Key Selected"에 해당, 자주 쓴다).
- 칸 색은 지금 규칙 그대로(빨강 = 이 시각에 키, 연한 빨강 = 어딘가 키, 주황 = 키 없는 포즈).
- 제목 줄에 "리그 노드 보기"가 켜졌을 때만 `노드: CharacterPortrait_Track_Move`를 덧붙인다.
- 빠지는 것: "선택 키의 노드 따라가기"(설정으로), Q/W/E/R·Auto Key·S·Esc(뷰포트 툴 줄로).

### 3.2 씬 (무대 세팅)

지금 #1–7 그대로, 줄만 정리: `id · 부모 · 노드` / `자리 · focus` / `오프셋 X Y · Rot Z` / `Scale X Y` / `Stage · Layer · 보이기` / `배역` / `카메라 zoom · pan X Y`. 제목은 "씬 — 고른 오브젝트의 배치(모션 키가 아니다)". 오브젝트를 고르지 않으면 "하이어아키에서 오브젝트를 고른다".

### 3.3 모션

이름 · 길이(초) · 끝 · 미리보기 mode · 메모 — 지금 #8 그대로. 그 아래에 **이 모션의 문제**(지금은 창 맨 아래 상태 줄 위에 전부 나온다)를 모션별로 보이면 찾기 쉽다 — 선택 사항.

### 3.4 설정

리그 노드 보기 · 선택 키의 노드 따라가기 · 스냅(켬/끔은 지금 툴바? → 여기로) · 스냅 간격 · 시간 표시 · 새 키 탄젠트 · 자동 저장. 맨 아래 "조작법" 접힘(지금의 긴 도움말).

### 3.5 뷰포트 위 툴 줄 (오른쪽에서 옮겨 오는 것)

```
[선택 Q] [이동 W] [회전 E] [배율 R]   |   [키 놓기 S] [버리기 Esc]   |   키 없는 포즈: 몸 X·Y
```
뷰포트 바로 위(또는 트랜스포트 줄 왼쪽)에 한 줄. Auto Key 토글은 하단 레인지 줄의 것 하나만 남긴다.

### 3.6 그래프 툴바에 보태는 것

- Stats 칸 옆에 **in / out 기울기** 숫자 칸과 **끊김** 토글(지금 인스펙터 #9의 기능). 툴바가 길어지면 두 줄.
- 복사/붙여넣기/삭제·현재 시각 명령·인비트윈은 단축키와 타임 슬라이더 우클릭 메뉴로 충분 — 버튼 없음.
