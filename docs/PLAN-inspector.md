# 인스펙터(오른쪽 패널) 정리 — 조사와 제안 (2026-10-28)

소유자: "뭐가 뭔지 알아볼 수 없다. 마야처럼 애니메이션 편의가 우선. 불필요한 것이 너무 많고 정리가 안 됐다. 탭이 필요하다."
이 문서는 지금 오른쪽에 있는 것 전부를 하나씩 보고, 남길 것·옮길 것·없앨 것을 정한 뒤, 탭 구성을 제안한다. 구현은 §5 순서로.

## 2. 원칙 (마야)

- **채널 박스가 주 화면**이다. 마야의 오른쪽은 채널 박스가 기본이고, 어트리뷰트 에디터는 탭으로 갈아탄다. 키를 놓는 동안 오른쪽에 다른 것이 보일 이유가 없다.
- **설정은 환경설정**으로. 작업 화면에 늘 떠 있지 않는다.
- **키 편집은 그래프 에디터 안**에서. 마야의 Stats(시각·값)·탄젠트 버튼은 그래프 에디터 툴바에 있다. 인스펙터에 또 두지 않는다.
- **버튼은 단축키의 그림자가 아니다.** 단축키가 있는 명령은 버튼을 두지 않거나, 두더라도 그 명령이 일어나는 자리(뷰포트·그래프) 곁에 둔다.
- **같은 토글은 한 곳에만.** Auto Key가 두 곳에 있다.

## 3. 결정 (소유자, 2026-10-28) — 오른쪽 패널 = 탭 셋, 설정·단축키는 창

```
┌ 채널 박스 │ 씬 │ 모션 ┐
```

- **채널 박스**(기본): `s1 · character` 제목 + 자리/깊이/연기 세 묶음(제목 클릭 = 접기, 설정에 남는다) + 키 없는 포즈 안내 한 줄. 버튼 없음.
- **씬**: 자리·focus / Layer·Stage·보이기 / 접힘 "시작 배치"(오프셋·Rot·Scale) · "카메라(샷)". 접힌 묶음은 값이 기본이 아니면 스스로 펼친다. id·부모·노드 칸은 뺐다(소유자) — F2·하이어아키 드래그가 대신한다. 배역은 모델·저작본·테스트까지 통째로 지웠다(옛 저작본이 없어 마이그레이션 없음).
- **모션**: 이름·길이·끝·미리보기 mode·메모.
- **설정 창**(툴바 "설정…"): 리그 노드 보기 · 무대 뼈대 보기 · 스냅 간격 · 새 키 탄젠트 · 시간 표시 · 자동 저장. 즉시 적용, 닫을 때 저장.
- **단축키 창**(툴바 "단축키 (F1)" · F1): 전역·뷰포트·그래프·도프 시트·타임 슬라이더·하이어아키 표, 읽기만.
- **없앤 것**: 키 섹션 전체(in/out 기울기·끊김·버튼 9개 — 기울기 칸만 그래프 툴바 Stats 옆으로), Q/W/E/R 버튼, 키 놓기·버리기, 인스펙터의 Auto Key(하단 토글만), "선택 키의 노드 따라가기"(규칙으로: 고르면 끔·모션을 바꾸면 켬), "보기" 섹션, 긴 도움말.
- **하이어아키**: 무대 뼈대(Shot/Pan/Zoom/Mask/DepthSystem/Framing…)는 기본 숨김 — `Scene › Stage00 › mid › 오브젝트`. 설정 "무대 뼈대 보기"로 전부 연다.

## 4. 단계 (전부 `dev`에 들어감)

| 단계 | 무엇 |
|---|---|
| **I1** 탭 셋 ✅ | 오른쪽을 TabControl 셋으로, 기본 채널 박스, 마지막 탭 기억 |
| **I2** 버튼·키 섹션 삭제 ✅ | Q/W/E/R·S·Esc·Auto Key 체크·따라가기 체크·키 섹션·도움말 삭제, 기울기 in/out 칸을 그래프 툴바로 |
| **I3** 설정 창 · 단축키 창 ✅ | 툴바 "설정…"·"단축키 (F1)" |

| **I5** 무대 뼈대 보기 ✅ | 기본 숨김, 설정으로 켬 |
